# Documentation

Le contenu de ce fichier a été fusionné dans [`README.md`](./README.md) — npmjs.com n'affiche que le README d'un package et ne suit pas les liens relatifs vers d'autres fichiers, donc un lien `README.md → DOCUMENTATION.md` y est mort. Garder tout dans un seul fichier évite aussi que les deux divergent avec le temps.

Voir `README.md` pour la référence API complète, le tutoriel pas à pas, et la personnalisation des textes/du style.
